Этот скрипт на Питоне хуифицирует любое слово (или даже несколько), которые вы введете.

## 🌐 Интерактивная веб-версия

Откройте файл `index.html` в любом браузере для использования интерактивной веб-версии с красивым интерфейсом!

## 💻 Консольная версия

Скачайте его себе на компьютер и запустите в консоли через:

```bash
python hui.py
```

## Как это работает?

Скрипт разбивает слова на слоги по гласным и заменяет начало слова на "ху-" с модифицированной гласной. Для слов с менее чем 4 слогами используется первый слог, для длинных слов - второй слог.
